# Python SDK v0.1.0 — April 11, 2026

Initial release of the StackLens Python SDK — synchronous and asynchronous tracing, prompts client, and full public API.

## New

- **Synchronous and async LLM call tracer** — `trace()` and `async_trace()` decorators capture model, tokens, latency, and cost for any LLM call and ship them to StackTrace.
- **Prompts client** — Fetch versioned prompt templates from FlowOps by environment and version slug. Supports A/B variant selection.
- **Full public API in `__init__.py`** — All user-facing symbols exported from the top-level package: `StackLensClient`, `trace`, `async_trace`, `get_prompt`, `StackLensError`.
